# Compilazione
Nella root del progetto:

cmake -B build && cmake --build build

# Esecuzione
Nella cartella build del progetto:

./sphereBattle*n*

dove *n* rappresenta la tappa del progetto

# Comandi
* Title Screen: premere qualsiasi pulsante della tastiera o mouse
* Selezionare i personaggi: click sinistro col mouse sul box contenente la sfera
